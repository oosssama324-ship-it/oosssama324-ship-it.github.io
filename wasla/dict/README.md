# معجم وَصلة

- `ar-words.txt`: كل الكلمات المقبولة في اللعبة (للتحقق وكلمات المكافأة).
- `ar-common.tsv`: الكلمات الشائعة مع تكرار استخدامها (لتوليد المستويات).

لذلك تُنشر هذه الملفات أيضًا بنفس الرخصة (انظر `LICENSE`).

التعديلات: حذف التشكيل، توحيد أشكال الألف (أ إ آ ← ا)، حذف أسماء الأعلام والاختصارات،
الاقتصار على الكلمات من حرفين إلى سبعة أحرف، وإضافة كلمات المستويات اليدوية.

لإعادة البناء: `python3 ../tools/build_dict.py` ثم `node ../tools/gen_levels.js`.
